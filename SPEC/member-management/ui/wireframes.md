UI Wireframes & Acceptance Criteria

1) Member List (mobile)
- Shows searchable list of members with memberNumber, name, and contact line.
- Tapping an item opens detail view.
- Search filters by memberNumber, firstName, lastName.

2) Member Detail
- Shows all member fields.
- If user has write role, show Edit and Delete buttons.
- Edit validates fields per spec before sending updates.

3) Add Member
- Form to create new member. memberNumber must be provided or generated by server.
- Only users with write roles can see this.

Acceptance
- Unauthorized user cannot see edit/add/delete actions.
- All flows use the API; changes are reflected in the repository file.
